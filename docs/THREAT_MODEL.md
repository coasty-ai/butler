# Threat model

Assets: local prompts/screenshots, provider keys, input authority, encryption keys, consent receipts, contributed bundles and provenance.

| Threat | Current control | Residual work |
|---|---|---|
| Model/page prompt injection | Strict action vocabulary; no shell/DOM/filesystem tools; local AX hit-test before every pointer action; activatable controls run unattended only with an allow-listed benign label (unknown labels in any language and consequential words require approval; unlabelled targets retry without input); built-in protected app floor (Terminal, iTerm, Script Editor, Automator, Disk Utility, Keychain Access, installers) that settings cannot remove; Finder double-click on anything but a verified folder, Finder Command-O/Command-Down and executable-looking files require approval; line breaks/tabs typed outside a document app's text area require approval; executable/local-file URLs denied; credentials/clipboard blocked; repeated denials pause | Semantic destination detection, unsafe editable surfaces, search-result pages are trusted by host, and adversarial live testing |
| Model-requested app launch (`open_app`) | Plain name only (no paths, URLs, arguments or documents); native resolution limited to allow-listed application folders, exact or unique whole-token match; installer/uninstaller/setup/updater names, the protected floor, configured protected apps, AppleScript/Automator applets, web-app wrappers and non-Mach-O executables refused; native re-resolution and bundle re-check at execute; Dock clicks redirected to `open_app`; unresolved names retry at most three times before takeover | A permitted but unexpected app can still be opened; launching an app can show its own first-run or restore UI; no per-app user allow-list |
| Model-requested file open (`open_file`) | Home-relative `~/` paths only (no `..`, control characters or URLs); native realpath must stay inside the home folder, outside `~/Library`, hidden paths, credential-like names and protected-app data, and be an existing document or folder; applications, scripts, installers, disk images, executables, Apple's unsafe-executable types (such as Terminal sessions) and internet-location files refused; the default app must exist, be one open_app could launch and allows (folders only in Finder, never System Settings, ProfileHelper, Shortcuts or Screen Sharing); resolution and handler bound to the frame and re-checked at execute; opened only with that checked app | Default apps for some document types can still run embedded content; adversarial file-type review |
| Local memory and system index | Stored encrypted with the vault key (AES-256-GCM, AAD `memory`); learning can be turned off and forgotten from Settings, and deleting a run removes its episode and correction weight; tutorial and synthetic runs never learn; only a bounded `MemoryContext` reaches the model (≤5 task-relevant preferences, ≤3 episodes, ≤12 apps, ≤10 files, ≤8 folders, ≤12 plan steps); Spotlight metadata only, with the same exclusions as `open_file`; corrections and typed slots pass `redactSecrets`; memory is labelled untrusted data in the instruction | Memory poisoning by a misleading run the user did not reject; file names can reveal private topics to the configured provider |
| Replayed plans (built-in intents, learned skills) | Replay needs an exact template match and repeated success; every step passes validation, policy, approval and native revalidation like a model action; pointer steps resolve by role and label against current grounded controls (ambiguous or missing controls abandon); app mismatch, decline, correction, pause, native error or a changed screen abandons the plan and returns control to the model | Wider live evaluation of learned skills across app updates and layout changes |
| Grounded control names in model context | `context.controls` names only (editable fields contribute title/description/placeholder, never values; secure fields skipped); strict schema (≤60 items, labels ≤80 characters, coordinates 0–1); credential span redaction; bounded 2,500-node/250 ms web walk; coordinates are hints and still pass hit-test and policy | Page-authored labels are untrusted text the model may follow; names can still contain personal data visible on screen |
| Spoken replies and self-activation | Replies are short and pass `speakableText` (no typed text, coordinates, full URLs, paths or credentials; no phrase with a control, approve or decline intent; no “assist”); half-duplex listening with a 0.8 s echo guard and a fresh recognition request after speaking; barge-in stops speech inside the helper; on-device natural voice (Kokoro) runs in a separate utility process with only HOME, TMPDIR, LANG and PATH in its environment, from pinned, SHA-256-verified downloads; natural cloud voice only in BYOM mode with an OpenAI key and explicit opt-in, text only, falling back to the on-device voice | Echo cancellation with Apple Speech is unvalidated; bystanders can hear replies |
| Follow-up listening without the wake phrase | Hands-free only, setting to disable, visible glow; stop latch signalled before `followup_detected`; no partials or levels before speech is detected; approvals there need confidence ≥ 0.75, one segment and the gate captured when the window opened, and are allow-listed to opening, quitting and navigation prompts (a test enumerates every policy question); approval windows open only after the question was spoken; merged, recovered and unconfirmed speech never approves | False detections with TVs or nearby speakers need on-device measurement |
| Misheard voice or stale correction | Local STT after hold/wake activation; endpointed commands; stop/pause routed only from final transcripts; unrecognized speech keeps an interrupted run paused; recovered hypotheses cannot approve; pending-action/confidence checks for approval; native interrupt and inference epoch | Signed device testing, background speakers, accents/noise; no speaker authentication |
| Malformed/stale action | Zod strict unions, finite normalized bounds, frame ID, application/geometry/fresh-screen checks in native helper | Real multi-monitor/window-move test matrix |
| Provider hangs, renderer stalls or helper crashes | Abort signal and 60-second provider deadline; transient outages pause the run; native process stop latch and event tap; input cleanup; helpers restarted with bounded backoff (the run pauses) and exit on parent death | Native drag/input interruption under CPU load; signed permissions QA |
| Secret capture | Protected-app capture exclusions and takeover (built-in floor plus settings); sensitive-input takeover; protected domains detected from window or web-area URL (including Safari); no screenshots during takeover | OCR and sensitive multi-window/browser coverage; avoid sensitive work in alpha |
| Provider exfiltration/routing | Direct configured HTTPS; local mode literal loopback only; redirects refused; cloud Ollama IDs rejected | Malicious local proxy cannot be constrained by this client; production egress audit |
| Renderer compromise | Sandbox/context isolation, narrow IPC, sender/frame validation, no navigation, restrictive CSP | CSP for dev deliberately allows local React refresh; dependency and release review |
| Journal theft/corruption | OS-wrapped master key, GCM authentication, per-event chain/sequence, encrypted frames, truncated-tail recovery | Key rotation, tail-rollback resistance, cryptographic erasure and backup policy |
| Silent/incomplete upload | Separate opt-in path, checksum-bound consent, per-chunk verification and final receipt | Production identity, concurrency and quotas |
| Ingest compromise/abuse | Loopback binding, possession tokens, encrypted quarantine, request/object limits, seven-day expiration | KMS/least privilege, per-user quotas, review workers, authenticated deployment |
| Consent withdrawal gaps | Verified deletion endpoint; exact approved bundle used for export | Derivative/backup deletion and synthetic release review |
| Forged Gym result | Exact fixture/distractor state and GUI vocabulary check | Trusted execution/trace provenance, richer graders and held-out variants |

Trust boundaries: renderer → IPC/main → policy → native controller/OS; main → chosen model provider; separate consent/review → contribution endpoint; quarantine → analyst → synthetic task registry. No automatic raw-data release crosses the final boundary.
