# Threat model

Assets: local prompts/screenshots, provider keys, input authority, encryption keys, consent receipts, contributed bundles and provenance.

| Threat                                                                                          | Current control                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Residual work                                                                                                                                                                                                                |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Model/page prompt injection                                                                     | Strict action vocabulary; no shell/DOM/filesystem tools; local AX hit-test before every pointer action; activatable controls run unattended only with an allow-listed benign label (unknown labels in any language and consequential words require approval; unlabelled targets retry without input); built-in protected app floor (Terminal, iTerm, Script Editor, Automator, Disk Utility, Keychain Access, installers) that settings cannot remove; Finder double-click on anything but a verified folder, Finder Command-O/Command-Down and executable-looking files require approval; line breaks/tabs typed outside a document app's text area require approval; executable/local-file URLs denied; credentials/clipboard blocked; repeated denials pause                                                                                                                                                                                                                                                                                               | Semantic destination detection, unsafe editable surfaces, search-result pages are trusted by host, and adversarial live testing                                                                                              |
| Model-requested app launch (`open_app`)                                                         | Plain name only (no paths, URLs, arguments or documents); native resolution limited to allow-listed application folders, exact or unique whole-token match; installer/uninstaller/setup/updater names, the protected floor, configured protected apps, AppleScript/Automator applets, web-app wrappers and non-Mach-O executables refused; native re-resolution and bundle re-check at execute; Dock clicks redirected to `open_app`; unresolved names retry at most three times before takeover                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | A permitted but unexpected app can still be opened; launching an app can show its own first-run or restore UI; no per-app user allow-list                                                                                    |
| Model-requested file open (`open_file`)                                                         | Home-relative `~/` paths only (no `..`, control characters or URLs); native realpath must stay inside the home folder, outside `~/Library`, hidden paths, credential-like names and protected-app data, and be an existing document or folder; applications, scripts, installers, disk images, executables, Apple's unsafe-executable types (such as Terminal sessions) and internet-location files refused; the default app must exist, be one open_app could launch and allows (folders only in Finder, never System Settings, ProfileHelper, Shortcuts or Screen Sharing); resolution and handler bound to the frame and re-checked at execute; opened only with that checked app                                                                                                                                                                                                                                                                                                                                                                          | Default apps for some document types can still run embedded content; adversarial file-type review                                                                                                                            |
| Local memory and system index                                                                   | Stored encrypted with the vault key (AES-256-GCM, AAD `memory`); learning can be turned off and forgotten from Settings, and deleting a run removes its episode and correction weight; tutorial and synthetic runs never learn; only a bounded `MemoryContext` reaches the model (≤5 task-relevant preferences, ≤3 episodes, ≤12 apps, ≤10 files, ≤8 folders, ≤12 plan steps); Spotlight metadata only, with the same exclusions as `open_file`; corrections and typed slots pass `redactSecrets`; memory is labelled untrusted data in the instruction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Memory poisoning by a misleading run the user did not reject; file names can reveal private topics to the configured provider                                                                                                |
| Replayed plans (built-in intents, learned skills)                                               | Replay needs an exact template match and repeated success; every step passes validation, policy, approval and native revalidation like a model action; pointer steps resolve by role and label against current grounded controls (ambiguous or missing controls abandon); app mismatch, decline, correction, pause, native error or a changed screen abandons the plan and returns control to the model                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Wider live evaluation of learned skills across app updates and layout changes                                                                                                                                                |
| Clipboard | Copy and cut are always refused, in policy and in the helper. Command-V alone is allowed only when the user's own task or correction contains the word paste and an identified text field has focus; policy marks that one press and the helper refuses every other clipboard chord, so a compromised model cannot paste a copied secret elsewhere or copy screen content out | The user's clipboard may hold a secret; the paste lands wherever the field is, so the field must be identified |\n| Menu items and named controls (`menu_item`, `click_control`)                                    | Names are resolved natively against the live accessibility tree at the moment of input, never trusted from the model: an unknown name is `TARGET_MISSING`, a shared name with no position `TARGET_AMBIGUOUS`, a greyed-out item `TARGET_DISABLED`, and nothing is pressed in any of those cases. The Apple menu and quit/log-out/restart/sleep/lock/shut-down items are refused in the helper as well as in policy. A resolved target goes through the same protected-application, secure-input, installer, protected-domain and consequential-label rules as a click, judged by the title the application itself publishes                                                                                                                                                                                                                                                                                                                                                                                                                                   | Menu and control titles are app-authored, untrusted text; an application can rename an item between the observation and the press, which is why the title is re-read and judged again at press time                          |
| Applications that publish no accessibility (Chromium/CEF such as Spotify, custom-drawn windows) | Native verdict `accessibility: "none"` only with Accessibility trusted, a frontmost window at least 200x120, a completed bounded walk that found nothing actionable, no usable focused element and no hit-test target (a loading window, a small panel or an empty desktop gets no verdict); reported on the surface and as `context.accessibility` so the instruction steers the model to the app's own menus (`context.menus`, at most 12 menus of at most 14 items, titles and shortcuts only, never menu contents) and to `menu_item`; there alone an unidentified pointer target or an unidentified focused field becomes one CONFIRM naming the application and the gesture, never the typed text, instead of a RETRY that ends in takeover; protected apps, secure input and uninstallers still take over, installers/setups/updaters are denied, credential text is still denied, and applications that do expose controls keep the unchanged RETRY; the only added routine chords are the app's own search (Command-K, Command-L) on a blind surface | The user approves a screen position, not a verified control; app-authored menu titles are untrusted text; a blind app can redraw between the question and the click                                                          |
| Grounded control names in model context                                                         | `context.controls` names only (editable fields contribute title/description/placeholder, never values; secure fields skipped); strict schema (≤60 items, labels ≤80 characters, coordinates 0–1); credential span redaction; bounded 2,500-node/250 ms web walk; coordinates are hints and still pass hit-test and policy                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Page-authored labels are untrusted text the model may follow; names can still contain personal data visible on screen                                                                                                        |
| Spoken replies and self-activation                                                              | Replies are short and pass `speakableText` (no typed text, coordinates, full URLs, paths or credentials; no phrase with a control, approve or decline intent; no “assist”); half-duplex listening with a 0.8 s echo guard and a fresh recognition request after speaking; barge-in stops speech inside the helper; on-device natural voice (Kokoro) runs in a separate utility process with only HOME, TMPDIR, LANG and PATH in its environment, from pinned, SHA-256-verified downloads; natural cloud voice only in BYOM mode with an OpenAI key and explicit opt-in, text only, falling back to the on-device voice                                                                                                                                                                                                                                                                                                                                                                                                                                        | Echo cancellation with Apple Speech is unvalidated; bystanders can hear replies                                                                                                                                              |
| Follow-up listening without the wake phrase                                                     | Hands-free only, setting to disable, visible glow; stop latch signalled before `followup_detected`; no partials or levels before speech is detected; approvals there need confidence ≥ 0.75, one segment and the gate captured when the window opened, and are allow-listed to opening, quitting and navigation prompts (a test enumerates every policy question); approval windows open only after the question was spoken; merged, recovered and unconfirmed speech never approves                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | False detections with TVs or nearby speakers need on-device measurement                                                                                                                                                      |
| Auto-resume after manual input                                                                  | Any unmarked input still latches the native helper instantly; the helper only reports idle kinds and durations (no coordinates or keys); main resumes only an unchanged manual hold (same event sequence, not listening) or a click hand-off, from a fresh observation with full policy; a hold in a window bound for a background run resumes only once its application is no longer frontmost and the last press, scroll or key landed outside the window (a hover moves neither flag), from two flags the helper adds to the idle report, and the helper gives no window back for it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | A user who pauses mid-task for more than three seconds sees the agent continue; say stop or press Escape to cancel                                                                                                           |
| Texted commands (iMessage channel)                                                              | Off by default and enabled only in Settings; the handle lives in the encrypted config, never read from `.env` at runtime; only the exact configured handle in a one-to-one chat is read, never `is_from_me` rows (our own updates and the owner's other devices are indistinguishable, so "note to self" threads deliberately do not work), group chats, attachments, tapbacks, app balloons or system events; a baseline row id taken when the channel starts and a five-minute freshness window stop a backlog or late iCloud sync from acting; strict vocabulary (`status`, `stop`, `pause`, `continue`, `do <task>`) with no approvals, settings or key access by text; credentials in a texted task are refused by `scanText`; 6 commands/minute and a 10-minute quiet period after 3 unknown commands; a texted task runs through the same policy, approval, pill and budgets as a typed one; the database is opened read-only and a body is copied only after every rule accepts the row                                                               | Anyone holding the owner's phone or spoofing SMS to that handle can start a task (approvals still gate consequential actions); Apple carries the content; no second factor on the text channel; SMS-only handles unsupported |
| Texted updates (outgoing)                                                                       | One line per run moment, deduplicated by the spoken-reply moment key, bounded to 300 characters, 8 per run and 20 per hour; only `speakableApproval`/`speakableText`/`speakableSummary` output, so no typed text, coordinates, full URLs, paths or credentials; no screenshots or partial transcripts; default sends updates only for tasks started by text                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | A run summary can still name an app or document; messages persist on both devices and in iCloud backups                                                                                                                      |
| Phone remote reached from outside the tailnet                                                   | Bound only to this node's Tailscale addresses (100.64.0.0/10, fd7a:115c:a1e0::/48), never 0.0.0.0, loopback or the LAN; peers outside those ranges refused before `whois`; Funnel and Serve never invoked, and a Serve/Funnel config on the port refuses startup; HTTPS with the node's own certificate when available, plain HTTP only inside WireGuard otherwise; every connection identified by the daemon's `whois`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | The coordination server could admit a node without Tailnet Lock; recommend enabling it. LocalAPI `cert` and serve-config paths unconfirmed against a live daemon (CLI fallback)                                                |
| Another tailnet member, a shared or tagged node, or a browser on the Mac                        | Only the Mac's own Tailscale login (pinned on first start); this Mac's own node, tagged nodes and shared-in nodes refused; an unknown phone of the right login sees only "Not allowed yet" until a switch is ticked on the Mac; no pairing route on the phone; at most 12 phones remembered                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | A second person sharing the user's Tailscale account is that user                                                                                                                                                             |
| Lost or unlocked phone                                                                          | Device switches default off; "approve" is a second opt-in and covers only routine questions (the follow-up window's allow-list minus `NEVER_BY_PHONE`); money, deletion, credentials, accounts, installs, running programs, sending, saving, signing, settings, blind surfaces and coding-agent relays stay Mac-only; approvals refused while someone is at the Mac; three replayed or forged nonces lock approvals for an hour (a stale gate never counts); "Lock phone remote" (Settings, menu bar) and "Forget this phone" revoke at once; the Tailscale admin console can remove the device                                                                                                                                                                                                                                                                                                                                                                                                                                                                | An unlocked phone with an allowed device can stop, steer and routine-approve until locked out                                                                                                                                 |
| Replayed or stale phone approval                                                                | Gate-bound single-use nonce per device (ten-minute life, withdrawn when the gate changes), the gate hashed from `currentGate()`; the tier re-checked in main before `approveFromVoice`; the runner restores and revalidates the screen before acting                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | —                                                                                                                                                                                                                             |
| A web page on the phone pointed at this Mac (DNS rebinding)                                    | `Host` must name this Mac (MagicDNS name or tailnet address, with the remote's port or none) or the request is answered 421 before any route; `Origin` is compared only to those names, never to the request's own Host; the cookie is `SameSite=Strict` and every POST needs the header token; over HTTPS the certificate name mismatches as well | In plain-HTTP mode (no certificate yet) the Host check is the one line of defence against rebinding |
| CSRF or a hostile page on the phone or the Mac                                                  | `SameSite=Strict; HttpOnly` cookie plus the same token in a custom header on every POST, `Origin` and `Sec-Fetch-Site` checks, JSON only, no CORS headers; a session is bound to the device that opened it; requests from the Mac's own address resolve to `Self` and are refused; a per-response CSP nonce with `default-src 'none'`; no local storage on the phone                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | —                                                                                                                                                                                                                             |
| Prompt injection through phone text                                                             | Same guard as typed text: credentials refused before the router; the deterministic router never approves from a `remote` source (a "yes" answers "Use the Approve button"); a steered task runs under the full policy, approvals and budgets; the pill says "From your phone." and never the text                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | A steered task still runs under the normal policy                                                                                                                                                                             |
| Screenshot leakage to the phone                                                                 | Off by default; the only option is a 24-pixel mosaic scaled up (layout and colour, no readable text), served only for the frame id the last status named, only to allowed phones, never pushed, never stored anew; no frame exists during takeover, secure input or protected surfaces; the view never carries `Frame.image`, screen text, typed text, full URLs or paths                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | The mosaic still shows the layout of whatever is on the selected display                                                                                                                                                      |
| Denial of service from the tailnet                                                              | 16 sockets, 2 event streams per phone and 6 in all, per-phone and per-address rate limits, 4 KB bodies, 30 s body and request timeouts; content-free traces (`route`, `verdict`, `tier`, hashed `device`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | —                                                                                                                                                                                                                             |
| Misheard voice or stale correction                                                              | Local STT after hold/wake activation; endpointed commands; stop/pause routed only from final transcripts; unrecognized speech keeps an interrupted run paused; recovered hypotheses cannot approve; pending-action/confidence checks for approval; native interrupt and inference epoch                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Signed device testing, background speakers, accents/noise; no speaker authentication                                                                                                                                         |
| Malformed/stale action                                                                          | Zod strict unions, finite normalized bounds, frame ID, application/geometry/fresh-screen checks in native helper                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Real multi-monitor/window-move test matrix                                                                                                                                                                                   |
| Provider hangs, renderer stalls or helper crashes                                               | Abort signal and 60-second provider deadline; transient outages pause the run; native process stop latch and event tap; input cleanup; helpers restarted with bounded backoff (the run pauses) and exit on parent death                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Native drag/input interruption under CPU load; signed permissions QA                                                                                                                                                         |
| Secret capture                                                                                  | Protected-app capture exclusions and takeover (built-in floor plus settings); sensitive-input takeover; protected domains detected from window or web-area URL (including Safari); no screenshots during takeover                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | OCR and sensitive multi-window/browser coverage; avoid sensitive work in alpha                                                                                                                                               |
| Provider exfiltration/routing                                                                   | Direct configured HTTPS; local mode literal loopback only; redirects refused; cloud Ollama IDs rejected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Malicious local proxy cannot be constrained by this client; production egress audit                                                                                                                                          |
| Renderer compromise                                                                             | Sandbox/context isolation, narrow IPC, sender/frame validation, no navigation, restrictive CSP                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | CSP for dev deliberately allows local React refresh; dependency and release review                                                                                                                                           |
| Journal theft/corruption                                                                        | OS-wrapped master key, GCM authentication, per-event chain/sequence, encrypted frames, truncated-tail recovery                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Key rotation, tail-rollback resistance, cryptographic erasure and backup policy                                                                                                                                              |
| Silent/incomplete upload                                                                        | Separate opt-in path, checksum-bound consent, per-chunk verification and final receipt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Production identity, concurrency and quotas                                                                                                                                                                                  |
| Ingest compromise/abuse                                                                         | Loopback binding, possession tokens, encrypted quarantine, request/object limits, seven-day expiration                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | KMS/least privilege, per-user quotas, review workers, authenticated deployment                                                                                                                                               |
| Consent withdrawal gaps                                                                         | Verified deletion endpoint; exact approved bundle used for export                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Derivative/backup deletion and synthetic release review                                                                                                                                                                      |
| Forged Gym result                                                                               | Exact fixture/distractor state and GUI vocabulary check                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Trusted execution/trace provenance, richer graders and held-out variants                                                                                                                                                     |

Trust boundaries: renderer → IPC/main → policy → native controller/OS; main → chosen model provider; separate consent/review → contribution endpoint; quarantine → analyst → synthetic task registry. No automatic raw-data release crosses the final boundary.
